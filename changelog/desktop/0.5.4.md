使用远程服务器时，消息选项、任务指派和 Agent 环境变量需要服务端支持。要让新启动的 Agent 使用自定义环境变量，或让 Antigravity 自动压缩上下文，运行 Agent 的电脑也需要支持这些功能的 daemon。

## 消息与对话

- Agent 可以在消息中提供单选或多选题。你可以直接点选、填写其他答案，也可以撤回自己的回答。
- 点消息作者的名字，即可在当前输入框中提及对方。一条消息中的多张图片会叠放显示。
- 重新打开对话时会恢复上次的面板布局。宽屏上可以把面板拉宽到 720 像素以上。

## 任务

- 可以把任务指派给人或 Agent，同时保留任务当前状态。任务详情会随变更刷新历史记录。
- 看板按状态分组展示任务，默认显示最近两周创建的任务，可通过创建时间筛选查看更早的任务。

## Agent

- 创建者可以在 Runtime configuration 中为单个 Agent 设置环境变量，下次启动时生效。
- Antigravity 支持用 `SILVERHAND_ACP_AUTO_COMPACT` 设置上下文压缩阈值。达到阈值后会在空闲时压缩，Activity Log 会显示压缩进度。
