## 消息与任务

- 在消息上点右键即可选择「在线程中回复」。
- 消息中的任务标签现在显示为任务卡，点击即可打开任务详情。
- 自己发出的消息里，引用回复块靠右对齐，内容仍从左到右阅读。

## Agent

- 新增 Antigravity runtime。安装 `agy` 后，可以选择模型、调整该模型支持的推理强度，并在运行中追加消息。使用远程服务器或独立 daemon 时，对应组件也需要支持 Antigravity。
- Claude、Codex、Grok 和 Antigravity 提供模型显示名称时，模型选择器会显示该名称。

适用于 Apple Silicon（arm64）Mac，提供 embedded 和 remote-only 两种安装包，均已通过 Developer ID 签名和 Apple 公证。
